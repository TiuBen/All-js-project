## 前端部署

##### 1.下载node.js

直接安装 node-v22.17.0-x64.msi

在终端输入以下命令，确认安装完毕。

```powershell
node -v
npm -v
```

##### 2.下载rustup-init.exe

双击安装，输入以下命令确认安装完成

```powershell
rustc --version
cargo --version
```

##### 3. 安装 Tauri CLI，创建项目

```powershell
cargo install create-tauri-app

#创建项目
npm create vite@latest flight-dispatch-system -- --template react

#选react，JavaScript,不创建git
#创建好后
cd flight-dispatch-ui
npm install

```

##### 4. 安装bootstrap

```
npm install bootstrap
```

##### 5. 添加Tauri支持

```
npm install --save-dev @tauri-apps/cli
npx tauri init
```

##### 6. 启动前端

```
npm run dev
npm run tauri dev
```

##### 7. 配置路由

```
#配置
npm install react-router-dom
```
