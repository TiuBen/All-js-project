- 做法：写 `db_seed/_extract_codes_user.mjs` 按语句抽取子集 → 生成 `db_seed/seed_codes_and_user.sql`（**数据版，不含 DDL**，

- 提取时踩的两个坑：
  1. 按「行尾分号」切语句时把前面的 `-- Name: xxx` 注释行也带进了语句体，`^CREATE TABLE` 锚定匹配全部失效 → 要剥掉前导注释行。
  2. `"user"` 表名带引号，但序列名是 `public.user_id_seq`（无引号）→ 拿带引号的 target 去比序列名会漏掉 user 的序列，
     SQL 里 `SET DEFAULT nextval('public.user_id_seq')` 就会指向不存在的序列。比对时要去引号。
- 生成脚本自带守卫：三张表必须存在且为空，否则 RAISE EXCEPTION 整份回滚（重跑已验证会被拦）。
- ⚠️ 又踩到 Windows 参数编码：bash 里 `psql -c "...中文..."` 同样会把中文按 GBK 传进去报「无效的 UTF8 编码字节顺序」。
  **带中文的 SQL 一律走 stdin heredoc 或 `-f` 文件**，别塞进 `-c`。
